# 数据与隐私

这份文档只描述这个 App 自己做了什么。**它管不了 DeepSeek 服务端怎么处理你的数据**——那部分看 [DeepSeek 隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)。

## 会离开手机的请求

只有四类，全部发给你填的服务地址（默认 `https://api.deepseek.com`）：

| 请求 | 什么时候发 | 带出去什么 |
| --- | --- | --- |
| `POST /anthropic/v1/messages` | 每次对话、深度思考、工具调用 | 你的消息、上下文历史、启用的技能文本、工具定义 |
| `POST /anthropic/v1/files` | 上传图片或文档时 | 文件内容 |
| `POST /v1/tools/asr` | 语音输入停止录音后 | 那段 WAV 录音 |
| `POST /v1/tools/tts` | 点朗读时 | 要朗读的文本 |

另外两个不打数据的小请求：`GET /models` 用来校验 API Key 是否有效（不产生费用），`DELETE /anthropic/v1/files/{id}` 用来删掉自己上传过的云端文件。

App 内「设置 → 隐私 → 数据去了哪里」把这张表原样显示出来，并附上当前服务地址。

## 留在本机的数据

| 数据 | 存哪 | 卸载后 |
| --- | --- | --- |
| 会话、消息、消息分支 | IndexedDB | 删除 |
| 草稿 | IndexedDB | 删除 |
| 附件原件（图片副本） | IndexedDB | 删除 |
| API Key、模型、模式、强度、语言、主题、服务地址 | localStorage | 删除 |
| 技能与 MCP 配置 | localStorage | 删除 |
| 原生侧写入的文件（`writeStoreFile`） | 应用私有目录 | 删除 |

没有账号体系，也就没有云端备份。换手机只能"导出历史对话"再"导入"，导出的 ZIP 里包含所有会话与本地图片原件，**不包含 API Key**。

## 没有什么

没有统计 SDK、没有崩溃上报、没有广告、没有 A/B 框架、没有第三方域名。`web/src` 里出现的 `https://` 只有官方文档链接与隐私政策链接，可以直接 grep 验证：

```bash
grep -rhoE 'https://[a-zA-Z0-9.-]+' web/src | sort -u
```

APK 只申请两个权限：`INTERNET`（发请求）和 `RECORD_AUDIO`（语音输入）。没有存储权限——相册走系统 Photo Picker，文件走 `ACTION_GET_CONTENT`，都不需要它。

## 训练这件事，App 管不了

**"是否用你的内容继续训练模型"是 DeepSeek 账户上的开关**，不在客户端里，请求体里也没有能关掉它的字段。

想彻底退出，得去官方产品里关：**设置 → 数据管理 → 关掉「数据用于优化体验」**。关掉之后，新对话不再进入训练；已经产生的对话要撤回，只能走官方渠道联系。

App 里那一栏的作用是把这件事讲清楚，并给一个跳转入口，而不是假装替你把开关关了。

## 中转的风险

服务地址是可配置的。一旦你把它改成第三方中转或自建后端，**你的 API Key、对话内容、上传的文件就都到了那一方手里**，本项目的所有承诺在那一刻失效。

直连官方地址时，请求只经过你和 DeepSeek 两方。

## 怎么删

- 单条对话：会话列表里删，连同它的附件一起删
- 全部数据：设置 → 隐私 → 删除全部对话与附件（不碰 API Key 与设置）
- 连 Key 一起清：设置 → 数据管理
- 保存的位置：设置 → 隐私 → 清除保存的位置
- 最彻底：卸载应用

## 做不到的保证

说清楚边界比喊口号有用：

- 这台手机若已 root、或有恶意输入法/无障碍服务，本机数据对它不设防
- 调试签名的 APK 没有经过应用商店审核，也不排除被人改包重签后分发——只从本仓库的 Releases 下载，并核对 SHA-256
- 系统的"应用备份"若开启，可能会把 App 私有数据一并备份到你的云盘
- 网页版跑在浏览器里，localStorage 与 IndexedDB 受浏览器同源策略保护，但装了恶意扩展就另说
